# MedExplain AI

MedExplain AI is an intelligent healthcare platform that transforms medicines, prescriptions, and medical reports into clear, reliable, and easy-to-understand insights for everyday users.

## Features

* Upload medicine images, prescriptions, and lab reports
* AI-powered medical explanation
* OCR text extraction from medical documents
* Simple understanding of medicines and reports
* Emergency warning detection for critical values
* Secure JWT Authentication
* Saved report history and dashboard

## Tech Stack

* Next.js 15
* TypeScript
* Tailwind CSS
* Shadcn UI
* MongoDB + Mongoose
* JWT Authentication
* OpenAI API
* Tesseract.js
* Cloudinary

## Goal

To make medical information simple, safe, and understandable for everyone.

## Disclaimer

This platform is for educational purposes only and does not replace professional medical advice or diagnosis.
